# Cubiz Lite

Cubiz Lite is a lightweight Minecraft shader pack designed to improve the game's visuals while maintaining excellent performance.

The project combines a clean lighting pipeline, realistic water, atmospheric effects, and a simple, customizable experience without aiming for photorealism.

## Features

- Dynamic lighting
- Soft shadows
- Improved atmosphere
- Better sky colors
- Volumetric-style fog
- Animated vegetation
- Bloom
- Color grading
- High-quality water
- Reflections
- Refraction
- Underwater effects
- Performance-focused design

## Requirements

- Minecraft: Java Edition
- Iris Shaders (recommended)
- Sodium (recommended)

## Installation

1. Download the latest release.
2. Place the ZIP file into your `shaderpacks` folder.
3. Enable Cubiz Lite from the shader menu.

Do not extract the ZIP.
